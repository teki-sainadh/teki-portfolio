## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Backend:** Node.js, REST APIs, Firebase, Supabase
- **Cloud:** AWS (Amplify, EC2, S3), Vercel, GCP
- **AI Tools:** Groq, Gemini, Lovable, Cursor, Claude Code
- **DevOps:** GitHub Actions, CI/CD, Linux, Networking

## Getting Started

```bash
# Clone the repo
git clone https://github.com/teki-sainadh/teki-portfolio.git
cd teki-portfolio

# Install dependencies
npm install

# Run locally
npm run dev
```
